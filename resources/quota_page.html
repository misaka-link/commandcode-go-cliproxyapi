CommandCode 账户与额度

支持 GOAT / Pro / Max，不支持 Go。新 key 联网核验身份和有效订阅后才保存。也可从 CPA 的 OAuth 登录项进行浏览器授权。仅没有邮箱的账户会自动查询一次额度。启用、禁用和删除请到认证文件页操作。

模型白名单

只有命中下列关键词/模式的模型才会注册（每行一个，也支持逗号分隔；支持 * 通配，按全名匹配，建议写成 *关键词*，如 *glm-5*；留空表示全部注册）。

模型黑名单

命中黑名单的模型会被排除（优先级高于白名单；每行一个，也支持逗号分隔；支持 * 通配；= 开头表示精确匹配，如 =zai-org/glm-5）。

OAuth 模型别名

把模型重命名为别名（原模型不再发布）。勾选「去掉前缀」时，所有模型按上游 ID 发布（如 deepseek/deepseek-v4.1-flash），不再保留 commandcode/ 前缀版本。

模型列表

「未过滤」展示上游目录返回的全部模型（含被白名单/黑名单/协议过滤掉的）；public ID 为经过前缀/别名后的 ID。「过滤后」是实际注册/发布的模型。
